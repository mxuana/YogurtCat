## 简体中文

### 项目介绍

酸奶喵（YogurtCat）是一款面向 Android 用户的 AI 图片生成应用。

项目支持用户自行配置 API 服务，提供图片生成、参考图片、角色（OC）管理、生成历史和应用内更新等功能。

本项目由 **mxuana** 开发和维护，采用 MIT 许可证开源。

### 主要功能

- 🎨 AI 图片生成与提示词输入
- 🖼️ 参考图片上传
- ⚙️ 用户自行配置 API 服务
- 📐 图片比例与分辨率设置
- 🐱 OC（原创角色）管理
- 📚 生成历史与任务管理
- 🔄 应用内版本更新
- 📱 Android 原生应用界面

部分功能可能依赖所配置的 API 服务及模型支持情况。

### 从源码构建

本项目使用 Kotlin 和 Android Gradle 构建系统。

1. 克隆本仓库。
2. 使用 Android Studio 打开项目。
3. 配置所需 Android SDK。
4. 同步 Gradle 并构建 APK。

正式发布版本使用独立签名配置，签名密钥不包含在公开仓库中。

## English

### About

YogurtCat is an open-source Android application for AI image generation.

It allows users to configure their own API services and provides image generation, reference images, original character (OC) management, generation history, and in-app updates.

Developed and maintained by **mxuana**.

### Features

- 🎨 AI image generation and prompts
- 🖼️ Reference image support
- ⚙️ User-configurable API services
- 📐 Image aspect ratio and resolution settings
- 🐱 Original character (OC) management
- 📚 Generation history and task management
- 🔄 In-app update support
- 📱 Native Android interface

Some features depend on the selected API provider and model capabilities.
